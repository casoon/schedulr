# ITC-2007 Track 3 (Curriculum-based Course Timetabling)

`comp01.ctt` and `comp11.ctt`: the two smallest instances of the International Timetabling
Competition 2007, Track 3 (Di Gaspero, McCollum, Schaerf; University of Udine). Format and
evaluation: <https://www.eeecs.qub.ac.uk/itc2007/curriculmcourse/report/curriculumtechreport.pdf>.

Taken from the OptaPlanner example data (Apache-2.0),
`optaplanner-examples/data/curriculumcourse/import/`, unmodified.

Best known values (penalty points, formulation UD2): comp01 = 5 (proven optimal),
comp11 = 0.
