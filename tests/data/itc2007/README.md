# ITC-2007 Track 3 (Curriculum-based Course Timetabling)

`comp01.ctt` und `comp11.ctt`: die beiden kleinsten Instanzen der International Timetabling
Competition 2007, Track 3 (Di Gaspero, McCollum, Schaerf; Universität Udine). Format und
Bewertung: <https://www.eeecs.qub.ac.uk/itc2007/curriculmcourse/report/curriculumtechreport.pdf>.

Bezogen aus den Beispieldaten von OptaPlanner (Apache-2.0),
`optaplanner-examples/data/curriculumcourse/import/`, unverändert.

Bekannte Bestwerte (Strafpunkte, Formulierung UD2): comp01 = 5 (bewiesen optimal),
comp11 = 0.
